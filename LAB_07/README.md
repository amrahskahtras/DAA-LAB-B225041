## Q1. Invert the Coin-Triangle
**Idea:** For a triangle with `n` rows, total coins `T(n) = n(n+1)/2`.
The minimum number of coins that must be relocated to flip the triangle is
```
M(n) = floor(T(n) / 3)
```
**Complexity:** O(1) per query, O(n) to tabulate for n rows.
Verified against known values: n=3 → 1 move, n=4 → 3 moves, n=5 → 5 moves.

## Q2. Super Egg Testing Experiment
**Idea:** Classic DP. `dp[e][f]` = minimum trials needed with `e` eggs and `f` floors.
```
dp[e][f] = 1 + min over x in [1..f] of max(dp[e-1][x-1], dp[e][f-x])
```
**Complexity:** O(E·F²) time, O(E·F) space (can be optimized to O(E·F log F) with binary search
or O(E·F) with the "moves vs floors" reformulation).
Verified: E=2, F=100 → **14** trials (the well-known classical answer).

## Q3. Reve's Puzzle (Tower of Hanoi, 4 pegs)
**Idea:** Frame–Stewart algorithm.
```
FS(n, p) = min over 1<=k<n of [2*FS(k, p) + FS(n-k, p-1)]
```
with base case `FS(n,3) = 2^n - 1` (classical 3-peg Hanoi).
**Complexity:** O(n²) with memoization (O(n) states × O(n) choices).
Verified: 8 disks, 4 pegs → **33** moves.

## Q4. Security Switches
**Idea:** Equivalent to the Chinese Rings / Gray-code puzzle.
```
M(n) = (2^(n+1) - 2) / 3   if n is even
M(n) = (2^(n+1) - 1) / 3   if n is odd
```
**Complexity:** O(1) per query using fast exponentiation (here O(1) via shift).
Verified: n=1→1, n=2→2, n=3→5, n=8→170 moves.

## Q5. Hitting a Moving Target
**Idea:** Since every move changes the target's position parity, shooting the sequence
`2, 3, 4, ..., n-1, n-1, ..., 3, 2` guarantees a hit for `n > 2` regardless of the
target's initial position or direction (first pass catches one parity class, second
pass catches the other).
**Complexity:** O(n) shots, O(n) algorithm; validated by simulating all initial
position/direction combinations.

## Q6. The Best Time to be Alive
**Idea:** Classic max-overlap / sweep-line problem. Convert each scientist's
(birth, death) into +1/-1 events, sort by year (deaths before births in a tie),
and scan while tracking a running count; the year with the maximum count wins.
**Complexity:** O(n log n) due to sorting; O(n) sweep.
Benchmarked for n up to 100,000 records — see `graph.png` for near-linearithmic
runtime growth.

## Q7. Matrix Chain Multiplication (MCM)
**Idea:** Standard interval DP.
```
m[i][j] = min over i<=k<j of [m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j]]
```
**Complexity:** O(n³) time, O(n²) space.
Verified against the classical textbook example
(dimensions 30x35, 35x15, 15x5, 5x10, 10x20, 20x25) → **15125** scalar multiplications,
with optimal parenthesization `((A1(A2A3))((A4A5)A6))`.
Benchmarked runtime for n up to 500 matrices — see `graph.png` confirming O(n³) growth.
